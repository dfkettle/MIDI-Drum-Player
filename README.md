# MIDI-Drum-Player
MIDI percussion sample player

The MIDI Drum Player (MDP) is designed to receive MIDI note data and play samples
of percussion instruments. The MIDI data may come from a hardware sequencer or
controller, a software sequencer, or any other source of MIDI percussion data.

If your OS doesn't support virtual MIDI cables (like Windows, for example), you
can install third-party software that does. For Windows, I recommend loopMIDI,
which is free and can be downloaded from here:

https://www.tobias-erichsen.de/software/loopmidi.html
